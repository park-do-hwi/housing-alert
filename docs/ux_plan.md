# UX 설계안 (v1)

참고: 임대분양정보(LH·SH·GH 임대 위주, 단순 목록), 분양알리미(사진 큰 카드, 단계별 일정, 광고·가입 있음).
우리 강점: 가입 없음 · 광고 없음 · LH/SH/GH/청약홈 통합 · 공고문 파일 링크.

## 원칙
1. 앱을 열고 5초 안에 "오늘 움직여야 할 공고"가 보인다.
2. 가입·권한 요구 없이 바로 쓴다. 관심 조건은 나중에, 선택.
3. 숫자(기간·가격·세대)가 제목보다 먼저 눈에 들어온다.
4. 모든 정보에 원문으로 가는 길이 있다. 추정값은 추정이라고 적는다.

## 화면 구조 (하단 탭 5개)
홈 · 지도 · 캘린더 · 관심 · 설정   (지도는 키 발급 후, 그 전엔 4개)

## 홈
- 상단 숫자 탭: 오늘 마감 · 접수 중 · 예정 · 무순위 · 결과  (누르면 목록이 그 단계로)
- 필터 한 줄: 지역 · 유형(분양/임대/장기전세/무순위) · 기관(LH/SH/GH/청약홈) · 내 조건
- 카드: [썸네일] 상태 배지(D-day/오늘 마감/N일 후 접수) / 제목 / 위치 / 세대·면적 / 가격 / 단계별 기간
  - 단계별 기간: 특별공급 · 1순위 · 2순위(청약홈 API로 수집 가능, 없는 기관은 접수 기간 한 줄)
  - 새로 올라온 공고는 NEW 표시(처음 본 지 24시간)
- 마감은 접어 둠(지금처럼). 관심 하트는 카드에서 바로.

## 상세
위에서 아래로: 썸네일/사진 → 배지·제목·위치 → 핵심 3칸 → 한눈에 보기(요약) → 청약 일정(타임라인)
→ 주택형별 공급 → 공고문 파일(내려받기 확인) → 부가 정보 → (경쟁률·당첨자: 마감 후)
하단 고정: [청약 신청/원문 공고] [관심] [비교]

## 사진
- 공공 데이터에 사진 없음. 단계: ① 지금: 유형·지역 색 타일 ② 지도 키 발급 시: 주소 기반 지도 이미지 ③ 시행사 홍보 이미지는 저작권 때문에 보류.

## 온보딩
없음. 첫 화면이 곧 목록. 알림 설정은 푸시 도입 때 "관심 지역 고르면 알려드려요" 한 번만 제안.

## 데이터 필요 (수집기)
- 청약홈: 특별공급/1·2순위 접수일, 당첨자 발표, 신청 URL, 경쟁률
- GH: apply.gh.or.kr 쪽 접수 기간(현재 gh.or.kr 게시판은 마감일 없음)
- LH: 공고별 상세 URL

## 우선순위
1) 홈 숫자 탭 + 단계별 기간 + NEW 배지  2) 청약홈 단계별 일정 수집  3) 상세 CTA 정리
4) 푸시 알림  5) 지도·썸네일  6) 경쟁률·당첨자
