## 부탁

## 앱이 하는 일
- SH·LH·청약홈의 **분양 / 무순위(줍줍)·잔여세대 / 장기전세 / 임대** 공고를 한곳에 모아 보여줍니다.
- 핵심 가치: "**오늘·이번 주에 내가 해야 할 청약**을 3초 안에 파악".
- 서버·로그인 없음. 내 정보(관심 지역·저장 공고)는 기기 안 파일에만 저장. 광고 없음.
- 사용자: 20~40대 무주택자, 처음 청약하는 사람 포함. 출퇴근길에 한 손으로 봅니다.

## 현재 화면 (Flutter, Material 3, 다크 테마 기본)
1. **온보딩** — 관심 지역(시도 칩), 공고 유형 칩, 포함/제외 키워드, 마감 알림 선택 → "시작하기"
2. **공고 목록(홈)** — 상단 필터 칩(지역 / 내 조건 / 분양 / 무순위 / 장기전세 / …), 아래에 단계별 섹션
   (마감 임박 → 접수 중 → 접수 예정 → 접수일 미확인 → 마감). 카드: 제목, 지역·출처, 접수 기간·세대수·분양가, 태그, 오른쪽 위 상태 배지("오늘 마감", "D-3", "내일 접수")
3. **공고 상세** — 태그, 제목, 지역·공고일·접수 마감·접수 시작·당첨자 발표·계약 시작·공급 세대·입주 예정·위치·사업주체·문의, 주택형별 표(전용면적·최고 분양가·세대수), 하단 "원문 공고 보기" / "비교 담기" 버튼
4. **캘린더** — 접수 마감일 기준 월간
5. **내 일정** — 북마크한 공고(접수 중 / 마감일 없음 / 마감됨)
6. **공고 비교** — 2~3개 공고를 표로 나란히
7. **알림 설정** — 지역·유형·키워드·마감 알림(D-3/2/1/당일), 내 정보 파일 내보내기/가져오기

하단 탭 4개: 공고 / 캘린더 / 내 일정 / 알림 설정

## 현재 느끼는 문제 ("뭔가 불편해")
- 목록이 길어 스크롤이 많고, 어디까지가 급한 건지 구분이 약함
- 카드에 정보가 많아 글자가 빽빽하고 위계(제목 > 일정 > 부가정보)가 약함
- 상세 화면이 "라벨-값" 표만 길게 이어져 한눈에 안 들어옴 (가장 중요한 건 "언제 접수하나 / 얼마인가 / 몇 세대인가")
- 태그 색(분양 초록·무순위 주황·장기전세 파랑·임대 보라)이 의미 구분 외에 통일감이 없음
- 전체적으로 "공공기관 표" 느낌이라 신뢰감은 있지만 매력·가독성이 부족

## 참고한 경쟁 앱 (이렇게 하고 싶다 / 다르게 하고 싶다)
- 청약알지: 앱을 열면 **오늘 접수하는 단지가 맨 위**, 이번 주 청약, 지도·캘린더·요약
- 집달력: 한 단지를 **특별공급→1순위→2순위→발표→계약 한 줄 타임라인**으로 표현
- 호갱노노: 지역별 "분양 예정 / 임박 / 청약 중" 구분
- 우리 방향: 광고 없이 깔끔하고 빠르게, "지금 할 일" 중심, 개인정보는 기기 안에서만

## 제약
- 구현: Flutter (Material 3). 커스텀 위젯은 가능하지만 복잡한 애니메이션·3D 지양
- 테스트 기기: 갤럭시 Z 플립5 (1080×2640, 세로로 긴 화면). 작은 화면·큰 글자 설정에서도 안 깨져야 함
- 한국어 전용, 다크/라이트 둘 다 지원
- 색 접근성: 색만으로 의미를 전달하지 말고 글자·아이콘 병행 (WCAG AA 대비)
- 법적 고지: "참고용 정보, 원문 공고에서 확인" 문구는 유지(작게)
