# Play 스토어 기본 등록정보 (ko-KR)

## 앱 이름
내집첫걸음 - 청약·분양·임대 알림

## 간단한 설명
SH·LH·GH·청약홈 분양·무순위 공고와 접수 일정을 한곳에서 확인하고 알림 받으세요

## 자세한 설명
내집첫걸음은 SH·LH·GH·청약홈에 흩어진 분양·무순위·임대 공고를 모아 보여 주고, 접수 일정을 놓치지 않게 알려 주는 정보 앱입니다.

■ 주요 기능
• 접수 중·마감 임박·접수 예정·무순위 공고를 한 화면에서 확인
• 관심 지역·유형의 새 공고 알림 (원할 때만 켜기)
• 달력으로 보는 접수·당첨자 발표 일정
• 분양 지도: 공고 위치를 지도에서 확인하고, 크게 보기에서 분양 지역을 표시
• 공고 상세: 분양가, 공급 세대·면적, 접수 기간, 원문 링크
• 관련 뉴스·영상 모아보기
• 내 일정: 관심 공고를 저장하고 접수일 확인

■ 개인정보
• 로그인·회원가입 없이 사용하며, 설정은 기기 안에만 저장됩니다.
• 위치 정보를 사용하지 않습니다.
• 알림은 동의한 경우에만 받으며, 설정에서 언제든 끌 수 있습니다.

■ 중요 안내
• 내집첫걸음은 민간이 만든 정보 서비스입니다. SH서울주택도시공사, LH한국토지주택공사, GH경기주택도시공사, 청약홈(한국부동산원) 등 어떤 기관과도 제휴하지 않았으며 해당 기관의 공식 앱이 아닙니다.
• 공고 정보는 각 기관이 공개한 공고를 바탕으로 하며, 일정 주기로 갱신되어 실제 공고와 시차가 있을 수 있습니다.
• 접수 자격·일정·분양가 등 정확한 내용은 반드시 원문 공고와 해당 기관에서 확인하세요.
• 앱의 정보는 참고용이며, 청약 신청과 그 결과에 대한 판단과 책임은 이용자에게 있습니다.
